Promo video files go here:
  modeani_<lang>.mp4  dubbed/narrated version per language (es, en, pt, he, fr, it, ...)
  modeani_es.mp4      fallback, shown with the chosen language's subtitles when no dub exists
  modeani.mp4         optional language-neutral master (last fallback)
  subs/<lang>.vtt     WebVTT subtitles per language
Until a file exists, the site shows the 'coming soon' card.
